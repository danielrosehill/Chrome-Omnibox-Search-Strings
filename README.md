# Chrome-Omnibox-Search-Strings

My Chrome omnibox site-search shortcuts as plain data: `search-engines.json`.

Each entry: `keyword` (type it in the address bar, then Space or Tab), `name`, `url` (`{searchTerms}` is replaced by the query), `active`.

To add one by hand: Chrome → Settings → Search engine → Manage search engines and site search → Site search → Add.
